## 二、验证自动构建（这是报告项目二、项目四要用的材料）

推送后：

1. 打开仓库页面 → 点顶部 **Actions** 标签
2. 应该看到一次 **CI** 运行（绿色对勾 = 成功）
3. 点进去，把页面截图，命名 `自动构建-成功.png`

**重要**：模板要求保留「失败及修复记录」。所以还要**故意制造一次失败**：

```bash
# 制造失败：把测试改错一行
# 打开 tests/test_auth.py，把 assert 改成断言错误的内容，例如
#   assert "登录" in resp.get_data(as_text=True)
# 改成
#   assert "完全不存在的文字" in resp.get_data(as_text=True)

git add tests/test_auth.py
git commit -m "test: 临时构造失败用例以验证构建校验能力"
git push
```

等 Actions 跑完 → **红色叉号**，截图命名 `自动构建-失败.png`

然后修复回来：

```bash
git revert --no-edit HEAD
git push
```

等 Actions 再次变绿 → 截图命名 `自动构建-失败修复后成功.png`

> 这样你就有「成功 → 失败 → 修复后成功」三张真实截图，正好满足模板「配置自动构建并保留成功和失败修复记录」。
